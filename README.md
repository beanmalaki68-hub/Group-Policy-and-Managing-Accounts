# Frist Task - Creating Security Groups and added user to them

This lab demonstrates how to create and manage Security Groups in Active Directory Users and Computers (ADUC). The video shows navigating to the domain, creating a new group, and configuring it as a Global Security Group. It then demonstrates opening a user's properties, selecting the Member Of tab, and adding the user to a security group such as GG-IT. This allows users to receive permissions based on their group membership instead of assigning permissions individually to each user.
